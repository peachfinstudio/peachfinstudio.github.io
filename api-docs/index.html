Peachfin Studio API Quickstart

This is a compact API reference page hosted on GitHub Pages. For full official API documentation, go to peachfin.studio/docs.

Base URL

https://api.peachfin.studio

Authentication

Authorization: Bearer YOUR_PEARCHFIN_API_KEY

Create speech job

curl -X POST https://api.peachfin.studio/v1/speech/jobs \
  -H "Authorization: Bearer $PEACHFIN_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "input": "Your startup demo is now ready.",
    "voice": "af_heart",
    "response_format": "mp3"
  }'

Get status

curl https://api.peachfin.studio/v1/speech/jobs/JOB_ID \
  -H "Authorization: Bearer $PEACHFIN_API_KEY"

Download audio

curl https://api.peachfin.studio/v1/speech/jobs/JOB_ID/audio \
  -H "Authorization: Bearer $PEACHFIN_API_KEY" \
  --output voiceover.mp3
