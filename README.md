# Peachfin Studio — AI Text-to-Speech and Product Launch Video Landing Page

Peachfin Studio is an **AI text-to-speech (TTS) platform** built for teams creating launch content, explainers, and campaign assets fast.  
This repository hosts the GitHub Pages source for [`peachfinstudio.github.io`](https://peachfinstudio.github.io), a lightweight public landing page and showcase for the Peachfin Studio brand.

## What this repo contains

- `index.html` and `styles.css` for the static landing page.
- Optimized social metadata for sharing launch videos and product updates.
- Hosted MP4 demo asset at `videos/03-speech-api-horizontal.mp4` for direct in-page playback.
- A local API docs mirror at `/api-docs/` (for quick reference from the landing page).
